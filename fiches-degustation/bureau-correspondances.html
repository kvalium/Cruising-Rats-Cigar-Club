Accès réservé au Comité

Accréditation administrative

Le mot de passe de consultation des archives ne permet pas l'envoi de correspondances officielles. Présentez votre accréditation distincte pour ouvrir ce bureau.

Le mot de passe n'est conservé qu'en mémoire pendant cette session du navigateur. Aucun courrier ne sera envoyé à l'ouverture.

Accès administratif requis. Aucun envoi automatique.

Rédiger un courrier

Destinataires : tous les membres enregistrés. Pipa, Cigarolo et le Président sont exclus.

Service des convocations

Collez un code nominatif généré dans le Bureau du Comité. Pour effectuer un essai, vous pouvez aussi créer un code de test ci-dessous. Le chronomètre démarre seulement sur la page de l'examen.

Essai technique réservé au Comité

Le code de test n'est rattaché à aucun membre réel et ne permet aucune homologation. L'accréditation du Bureau du Comité reste nécessaire.

Le code créé sera automatiquement reporté dans le champ ci-dessus. Aucun courrier ne sera envoyé.

Le courrier intégral reste celui du HTML historique : il conserve tous ses textes, illustrations et encadrés. La personnalisation se fait par les autres champs.

Pour les convocations, le code doit être un code d'invitation actif à usage unique et de 64 caractères. Vérifiez le destinataire et le code avant de confirmer tout envoi.

L'envoi nécessite une confirmation. Un courrier expédié ne peut plus être modifié ; un nouveau courrier peut en reprendre le contenu.

Épreuve avant expédition

Candidatures à relancer

Courriers de proposition envoyés depuis au moins 7 jours, sans réponse signalée au registre. Le Comité doit vérifier la boîte de réception avant de relancer.

Registre des transmissions

Les brouillons, envois et états de distribution sont enregistrés dans Cloudflare D1.

Modèles officiels

Le HTML complet est la source unique de l'aperçu et des envois Resend. Vous pouvez modifier la mise en page et les textes ; les éléments personnalisés dans « Nouveau courrier » restent appliqués à l'envoi.
