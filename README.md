# Cruising Rats Cigar Club

Site statique du CRCC.

## Structure

- `index.html` — présentation
- `activites.html` — activités
- `degustation.html` — comment déguster un cigare
- `actualites.html` — dernières actualités
- `contact.html` — contact
- `reglement.html` — règlement intérieur
- `css/style.css` — style graphique commun

Le site est volontairement sans framework ni dépendance : HTML + CSS uniquement.
